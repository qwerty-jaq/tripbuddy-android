# TripBuddy – Android Travel Companion App

An Android app for planning trips, tracking travel costs, and saving travel memories with photos and music. Built in Java with Android Studio as part of my Mobile Application Development module (Eduvos, 2025).

## Features

- **Login & sessions** – simple login that remembers the user between app launches
- **Trip Planner** – pick a destination and date, choose activities (sightseeing, hiking, dining, museums), and see the total cost worked out automatically
- **Budget** – view the cost of your last planned trip
- **Memories** – write a travel memory with location, date, mood, a photo, and background music, saved to a local database
- **Gallery** – browse saved photos and open them full screen
- **Settings** – choose the app language
- **Travel points (TES)** – earn points as you use the app

## Built with

- Java
- Android SDK (min SDK 24, target SDK 36)
- SQLite (local database for trips and memories)
- SharedPreferences (login session, settings, points)
- Material Components

## How to run

1. Clone this repo, or download it as a ZIP and extract it
2. Open the folder in **Android Studio**
3. Wait for Gradle to finish syncing
4. Press **Run ▶** to start it on an emulator or a connected phone
